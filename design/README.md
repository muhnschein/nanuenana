# Nanünana UI/UX design

Silica mockups, one per screen, kept as Design canvas.

- `canvas/project/canvas.json`: board layout, rows by area (first start, places, add place, place and warning, settings and about, cover and notifications, later countries).
- `canvas/project/*.dc.html`: one artboard per screen or state, 400×860 portrait, taller where a whole scrolled page shows; `ambience` tweak dark/light.
- `canvas/project/silica.css`: Silica style kit all boards share.
- `STYLE.md`: idioms, sizes, level colours.

Boards `AirRaidNotice`, `PlaceAirRaid`, `NotOffered` show later countries; not built yet.
